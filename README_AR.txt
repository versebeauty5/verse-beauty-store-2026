Verse Beauty — نسخة PostgreSQL

المتجر الآن يعمل عبر Backend/API وقاعدة PostgreSQL.
المتطلبات: Node.js 18+ وPostgreSQL.

1) أنشئ قاعدة PostgreSQL.
2) في الطرفية داخل المجلد: npm install
3) اضبط DATABASE_URL وJWT_SECRET وADMIN_PASSWORD اختيارياً.
4) شغّل: npm start
5) افتح: http://localhost:3000/start.html

بيانات الإدارة الافتراضية: admin / verse2026 إذا لم تضبط ADMIN_PASSWORD.
لا يوجد دفع إلكتروني؛ الطلبات تحفظ في قاعدة البيانات ثم يفتح واتساب للتأكيد.
